# Срокомер · 유통기한 체크

Android-приложение для учёта сроков годности в корейском супермаркете.

**Скачать:** раздел [Releases](../../releases/latest) → `srokomer.apk`.

- Живой сканер штрих-кодов: наводите камеру — код считывается сам
- Поиск названия и фото по штрих-коду (Open Food Facts) + запоминание своих товаров
- Распознавание корейского текста с упаковки (название и срок годности) прямо на телефоне
- Категории, отсчёт дней до окончания, сортировка, поиск, заметки
